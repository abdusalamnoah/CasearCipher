# CaesarCipher
Coding a basic encryption and decryption using the Caesar Cipher

First we define the alphabet in order. We then ask the user for what they want their key to be (how many letters shifted within the alphabet). We start at position 0 of the text we wish to encrypt then we separate the text into a list to make it easier to manipulate each letter. We then begin the for loop over the text (making sure to create a copy while we manipulate the original to prevent logical or syntax errors). We check if the position within the text is a letter. If it is, we then use modulo shifting where we say a value is congruent to another mod 26 so, for example, if we have the word zigzag and we wish to shift by 3, we start with z, which is index 25, add 3, summing 28 and divide by 26 where we get 1 remainder 2 which, if we did 2 mod 26, we get 0 remainder 2; therefore, in modular arithmetic, 28 is the same as 2 mod 26 so shifting by 28 gives the same result as shifting by 2. This means z will shift to index 2 in the alphabet, c, and will, therefore be replaced by c. This is done to every letter in the text then we re-join the text back into a string then return it.

Once again, we define the alphabet and establish where we start within text (index 0). We start a for loop which goes 26 times for every possible key shift in an encrypted caesar cipher. We then turn our text into a list every increment of the for loop to ensure we find the correct shift at the end. Then we do the reverse of what was explained about encrypting: instead of calculating using modular arithmetic what we jump forward to, we attempt to do it in reverse with every possible key shift (0-25) upon each letter. This is printed out each time and then we can go through and find the real word and the key.
